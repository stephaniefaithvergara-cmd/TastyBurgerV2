# Tasty Burgers

A responsive **React + TypeScript + Vite** burger shop web app.

## Features

- Tasty Burgers poster-inspired red and yellow visual design
- Philippine peso (₱) pricing
- Burger and fries menu
- Provided fries product images
- Ratings and review counts
- Local favorites with clickable heart controls
- Search and category filters with real-time multi-field matching
- Case-insensitive search supporting product names, categories (Burgers, Fries), and aliases
- Instant search bar with clear button, Escape key support, and automatic restoration
- Contextual no-results empty state with "No menu item found" feedback and clear action
- Full responsive header search across desktop, tablet, and mobile screens
- Cart with plus/minus quantity controls
- Animated solo hero burger
- Responsive navigation and cart drawer
- Reduced-motion accessibility support

## Development and Build

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run production build
npm run build

# Preview production build
npm run preview
```
